# Test Scenarios - Automation Exercise

## 1. User Registration
- Verify that a new user can register successfully.
- Verify registration with valid user details.
- Verify registration with invalid or missing required details.

## 2. Login
- Verify login with valid credentials.
- Verify login with invalid credentials.
- Verify login with incorrect email and valid password.
- Verify login with valid email and incorrect password.
- Verify logout functionality.

## 3. Product Browsing
- Verify that products are displayed correctly.
- Verify that product categories can be accessed.
- Verify that product details can be viewed.
- Verify product search functionality.

## 4. Shopping Cart
- Verify that a product can be added to the cart.
- Verify that multiple products can be added to the cart.
- Verify product quantity can be updated.
- Verify a product can be removed from the cart.
- Verify cart details are displayed correctly.

## 5. Checkout
- Verify that the user can proceed to checkout.
- Verify checkout details are displayed correctly.
- Verify that an order can be placed successfully.

## 6. Contact Us
- Verify that the Contact Us form can be submitted.
- Verify required fields are validated.

## 7. Product Review
- Verify that a user can submit a product review.

## 8. UI and Compatibility
- Verify important pages are displayed correctly.
- Verify the website works correctly on supported browsers.
- Verify navigation between important pages works correctly.
