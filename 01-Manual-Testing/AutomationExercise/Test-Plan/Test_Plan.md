# Test Plan - Automation Exercise

## 1. Project Overview

Automation Exercise is an e-commerce website used for practicing software testing.

The objective of this project is to perform manual testing of the application's major functionalities and identify defects.

## 2. Testing Objectives

- Verify that the application works according to its requirements.
- Identify functional defects.
- Verify important user workflows.
- Ensure a good user experience.

## 3. Scope of Testing

The following areas will be tested:

- User Registration
- Login and Logout
- Product Browsing
- Product Search
- Product Details
- Shopping Cart
- Checkout
- Order Placement
- Contact Us
- Other important functionalities available on the website

## 4. Testing Types

- Functional Testing
- UI Testing
- Smoke Testing
- Regression Testing
- Retesting
- Compatibility Testing

## 5. Test Environment

- Application: Automation Exercise
- Browser: Google Chrome
- Testing Type: Manual Testing

## 6. Deliverables

- Test Plan
- Test Scenarios
- Test Cases
- Test Execution Report
- Bug Reports

## 7. Entry Criteria

Testing will start when the application is accessible and the required functionalities are available for testing.

## 8. Exit Criteria

Testing will be completed when planned test cases have been executed and identified defects have been documented.

## 9. Defect Management

Identified defects will be documented with:

- Bug ID
- Title
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority
- Status
