# Automation Exercise - Manual Testing Project

## Project Overview

Automation Exercise is an e-commerce website used for practicing software testing.

This project focuses on manual testing of the application's major functionalities.

## Testing Areas

- Test Planning
- Test Scenarios
- Test Cases
- Test Execution
- Bug Reporting

## Testing Approach

Testing will be performed based on the actual functionality available on the website.

## Tools

- Browser
- GitHub
- Jira (for bug tracking)
