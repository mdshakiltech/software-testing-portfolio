**TC_NAV_01:** Verify Home page Navigation.
  
 **Module:** Navigation
 
 **Objective:** To verify that user can navigate to the Home page.
 
 **Precondition:**
- The website is accessible.
- The browser should be working.

 **Test Data:**
- https://www.ShoppersStack.com

 **Test Steps:**
- Open the Google chrome.
- Enter the ShoppersStack website url in the address bar.
- click enter.
- wait for the website to load completely.
- locate the home option in the page.
- click on the Home option.
- Verify the home page content is visible.

 **Expected result:**
- The Home page should be open successfully.
- The page content should load correctly.
- No unexpected error should be display.

 **Actual Resuly:**
-  The Home page is open.
-  No error message is visible.

 **Status:**
   Pass
