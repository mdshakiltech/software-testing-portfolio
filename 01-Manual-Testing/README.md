# ShoppersStack - Manual Testing Project

## Project Overview

ShopperStack is an e-commerce web application used for practicing
Manual Software Testing.

## Modules Tested

- Registration
- Login
- Home Page
- Product Search
- Product Details
- Add to Cart
- Cart
- Checkout
- Address
- Order
- Logout

## Testing Types

- Functional Testing
- Positive Testing
- Negative Testing
- Smoke Testing
- Sanity Testing
- Regression Testing
- Retesting

## Testing Deliverables

- Test Plan
- Test Scenarios
- Test Cases
- Bug Reports
- Test Execution Report
- Screenshots
